What it is

This is the Eco Infra Studio: a place and a program, open climate and park data, the city's rules, a search for a code-passing envelope, and a Blender file when the studio API is running on this machine.

What you can do

  • Enter an address, lot size, building program, budget, and sustainability options.
  • Run the studio so it looks up climate, green space, zoning, cost, and code checks.
  • Open the massing and download the Blender, STL, and GLB files when generation finishes.
